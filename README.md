# CEP-01-Linux

## Cloud Engineering Portfolio — Project 01: Linux

### Project Overview

CEP-01-Linux is the first project in my Cloud Engineering Portfolio (CEP).

This project establishes the Linux foundation required for cloud and infrastructure engineering. It focuses on practical administration of an Ubuntu Linux server, including system configuration, user and permission management, package management, networking, services, security, automation, monitoring, and troubleshooting.

The project is designed as a hands-on enterprise-style environment where Linux administration principles are applied through practical tasks, documented procedures, automation scripts, testing, and evidence.

### Project Objective

The primary objective of this project is to develop and demonstrate practical Linux system administration skills that form the foundation for cloud engineering and DevOps.

The project will demonstrate the ability to:

- Deploy and configure an Ubuntu Linux server.
- Manage users, groups, permissions, and ownership.
- Install and manage software packages.
- Configure and troubleshoot networking.
- Manage Linux services and processes.
- Apply basic server security and hardening.
- Automate administrative tasks using Bash.
- Monitor system resources and services.
- Troubleshoot common Linux problems.
- Document configurations, procedures, and test results.

### Project Scope

The project covers the configuration, administration, security, automation, and documentation of an Ubuntu Linux server.

The implementation will be performed through practical hands-on exercises and documented as part of the Cloud Engineering Portfolio.
